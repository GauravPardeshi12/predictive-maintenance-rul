## Why use Path instead of string paths?
- Cross-platform compatibility
- Cleaner path handling
- Better readability

## Why use logging instead of print()?
- Easier debugging
- Persistent execution history
- Different log levels

## Why add dataset_id?
- unit_id is reused across FD001–FD004
- Prevents incorrect grouping
- Creates a composite key with unit_id

## Why use vectorized operations?
- Faster than Python loops
- More readable
- Optimized through NumPy
